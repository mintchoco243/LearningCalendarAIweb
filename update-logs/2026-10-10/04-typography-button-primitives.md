# 04 — Typography and button primitives

**What:** Added shared Button, Heading, and Text primitives with Storybook coverage for variants, long content, and button states.

**Why:** The approved theme needs reusable, accessible content primitives before page-level composition changes.

**Alternative considered:** Using white text on the primary red action to mirror the gaming reference; rejected because it fails AA contrast at the approved action colour.

**Follow-ups:** Apply primitives to existing page components only when requested.
