# Overview navigation and card metadata

## What changed

Changed overview labels to the H5 type treatment, aligned the main navigation's
typeface and size with the Learning Calendar wordmark, and made the My learning
overview card open the My learning view. Reduced Activity Card schedule,
location, and trainer metadata to 12px normal-weight text.

## Why

The overview needed clearer hierarchy and its registration count needed a direct
path to the relevant view. Dense card metadata competed with the course title.

## Alternative considered

Making the count alone interactive would create a smaller, less discoverable
target. The whole My learning card is now a keyboard-accessible control.

## Follow-ups

If overview cards become reusable components, move their shared styles and
interaction contract out of the page stylesheet.
