# 14 — Use approved skill-path artwork

**What:** Replaced the CSS-reconstructed hero visual with the approved skill-path mockup artwork, framed to show its right-side key visual. Added a pointer-following red spotlight above the artwork that disappears when the pointer leaves.

**Why:** The CSS version did not preserve the mockup's composed terrain, atmosphere, and platform treatment. Using the approved artwork is the only direct route to visual parity while keeping the live hero copy and CTA in the established system font. The spotlight retains the requested reactive quality without making decorative nodes appear clickable.

**Alternative considered:** Continuing to approximate the scene with CSS geometry was rejected because each simplification moved the implementation further from the approved mockup.

**Follow-ups:** Replace the artwork with a dedicated right-panel export if the visual needs to scale independently from the current hero proportions.
