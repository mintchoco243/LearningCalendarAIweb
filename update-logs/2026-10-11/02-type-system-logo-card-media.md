# Type system, logo, and activity-card media

## What changed

Replaced the shared type system with Chakra Petch headings and Montserrat body
text. Added H1–H6, large body, body, small body, and label tokens, then exposed
them in Foundations and Typography stories. The active site uses the same CSS
variables and primitives.

Replaced the `G` wordmark with the supplied Garena logo and renamed the product
to `Learning Calendar`. Activity Cards now use a top media region, Montserrat
for category and registered labels, and a larger highlighted Chakra Petch title.

## Why

The previous mix used monospaced text in dense schedule content. The new
heading/body pairing keeps the gaming character in hierarchy while improving
readability for calendar details and descriptions.

## Alternative considered

Keeping abstract-only card art would align with the earlier mood-board note but
would not meet the current request for an image placeholder. Category-matched
remote images keep the component reusable until owned course imagery is ready.

## Follow-ups

Replace the remote placeholder images with approved internal course artwork when
available.
